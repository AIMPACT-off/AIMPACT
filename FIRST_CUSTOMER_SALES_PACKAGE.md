# AIMPACT FIRST CUSTOMER SALES PACKAGE — 2026-09-30

## Positioning
AIMPACT helps businesses turn one real operational problem into an AI-supported workflow that can be measured and improved.

## 5 SECONDS
BUSINESS PROBLEM → AI INTELLIGENCE → DECISION → WORKFLOW → RESULT

## 30 SECONDS
AIMPACT does not sell a list of AI tools. It identifies where AI can create operational value, selects the required capability, designs the workflow and defines how the result will be measured.

## 2 MINUTES
1. Discovery — confirm the real problem.
2. Audit — map the current process.
3. Decision — identify AI capabilities, tools and human controls.
4. Workflow — design the smallest useful implementation.
5. Measurement — compare actual before/after data.

2. Who performs it?
3. How often?
4. What tools are currently used?
5. Where does work get delayed or reworked?
6. What must remain human-controlled?
7. What would make the pilot successful?
