# AIMPACT CUSTOMER DELIVERY FLOW

DISCOVERY
→ AUDIT
→ PROPOSAL
→ PAID PILOT
→ WORKFLOW DESIGN
→ IMPLEMENTATION
→ QA
→ MEASUREMENT
→ CUSTOMER FEEDBACK
→ CASE STUDY
→ PRODUCTIZATION

## Gate 1 — Discovery
Confirm the actual problem. Do not convert a hypothesis into a customer problem without evidence.

## Gate 2 — Audit
Map the current process and identify AI opportunities, risks and measurement points.

## Gate 3 — Proposal
Define scope, deliverables, assumptions, timeline and commercial terms. External proposal requires owner approval.

## Gate 4 — Paid Pilot
Payment is recorded only after real payment is received. No booked or potential value is treated as revenue.

## Gate 5 — Implementation
Build the smallest useful workflow. Keep human approval where required.

## Gate 6 — QA
Test inputs, outputs, failure handling, permissions and repeatability.

## Gate 7 — Measurement
Compare before/after using actual data.

## Gate 8 — Productization
Extract reusable patterns, templates and workflow components without exposing customer-confidential information.
