## NORTH STAR
PROBLEM → INTELLIGENCE → DECISION → WORKFLOW → EXECUTION → RESULT → OUTCOME DATA → BETTER DECISION

## OPERATING LOOP
VISION → ANNUAL OBJECTIVES → QUARTERLY OBJECTIVES → MONTHLY TARGETS → WEEKLY PRIORITIES → DAILY EXECUTION → MEASUREMENT → REVIEW → CORRECTION → BETTER EXECUTION

Plans are not outcomes. Only verified change counts as progress.

## KPI INTEGRITY
Never confuse:
- POTENTIAL ≠ PIPELINE ≠ BOOKED ≠ PAID ≠ REVENUE
- PROSPECT ≠ LEAD ≠ QUALIFIED LEAD ≠ CUSTOMER
- DEMO ≠ REAL CUSTOMER CASE

## KPI HIERARCHY
CUSTOMER: Leads / Discovery / Proposal / Paid Pilot / Customers
REVENUE: Revenue / Pipeline / MRR / Repeat Revenue
PRODUCT: Audit / Workflow / Implementation / Productization
DATA: Problems / Processes / Workflows / Outcomes / Verification
DISTRIBUTION: Traffic / Search / Content / Inbound / Outbound
OPERATIONS: Reliability / Security / Automation / Data Quality

## REVIEW CADENCE
DAILY: company state, bottleneck, goal, highest-impact action, DONE / VERIFIED / IMPACT / BLOCKED / NEW DATA / CUSTOMER SIGNAL / REVENUE SIGNAL / NEXT ACTION.

WEEKLY: CUSTOMER → REVENUE → PRODUCT → OUTCOME → DATA → SALES → DISTRIBUTION → TECHNOLOGY → SECURITY → BRAND → COMPETITION; answer WHAT MOVED, WHAT DID NOT MOVE, WHY, WHAT SHOULD STOP, WHAT SHOULD DOUBLE, and the one highest-impact action.

MONTHLY: last month vs current month; UP / DOWN / FLAT / UNKNOWN; customer, revenue, productization, data moat, cost, brand, operations.

QUARTERLY: market, customer, product, revenue, data, competition, moat; change strategy when evidence supports it.
