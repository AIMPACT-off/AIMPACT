## 본문

AI를 도입하려고 할 때 가장 먼저 떠오르는 질문은 “어떤 도구가 가장 좋을까?”입니다. 하지만 실제 업무를 바꾸려면 질문의 순서를 바꿀 필요가 있습니다.

**어떤 도구를 쓸지 결정하기 전에, 지금 업무가 어디에서 지연되고 반복되는지부터 확인해야 합니다.**

### 업무 흐름을 먼저 나눠보세요

상품 등록과 콘텐츠 발행 과정을 예로 들어 보겠습니다.

상품 정보 수집 → 이미지 확인 → 설명 작성 → 내부 검토 → 수정 → 최종 등록

시간이 오래 걸린다고 해서 원인이 하나라고 단정할 수는 없습니다. 정보 전달이 늦거나, 검토 기준이 불명확하거나, 수정 요청이 여러 번 오갈 수 있습니다. 문제를 구분하지 않은 채 도구부터 도입하면 기존 과정에 도구 하나만 더 추가될 수 있습니다.

### 자동화 전에 확인할 다섯 가지

1. **입력:** 업무를 시작하려면 어떤 정보가 필요한가?
2. **담당:** 각 단계는 누가 처리하고 승인하는가?
3. **반복:** 같은 정보를 다시 입력하거나 같은 작업을 반복하는가?
4. **예외:** 정보 누락이나 오류가 발생하면 어떻게 처리하는가?
5. **검증:** 결과가 정확한지 누가 어떤 기준으로 확인하는가?

이 다섯 가지를 정리하면 AI가 맡을 수 있는 작업과 사람이 직접 판단해야 할 작업을 구분하기 쉬워집니다.

### 성과는 도입했다는 사실만으로 증명되지 않습니다

AI 도구를 연결하거나 자동화 코드를 작성했다고 해서 업무 개선이 확인된 것은 아닙니다. 실제 변화를 확인하려면 도입 전후의 기준이 필요합니다. 예를 들어 처리 시간, 수작업 횟수, 수정·재작업 건수, 처리량을 같은 기준으로 기록해야 합니다.

측정 자료가 없다면 절감 효과를 확정적으로 말할 수 없습니다. 먼저 기준을 기록하고, 작은 범위에서 시험한 뒤 결과를 확인하고 확대하는 편이 안전합니다.
