# AIMPACT SALES MATERIAL

## What AIMPACT does
AIMPACT helps e-commerce, fashion, retail, marketing and content teams identify repetitive work that can be improved with AI, then designs and implements the workflow.

## First conversation
Do not start with a tool list. Start with one real process:
- What task is repeated?
- How often?
- How long does it take?
- Who does it?
- Which tools are used now?
- Where does the work get stuck?
- What would a successful outcome look like?

## AI QUICK AUDIT
Short discovery for one business process.
Output:
1. AI-applicable tasks
2. Candidate tools
3. Draft workflow
4. Automation opportunities
5. Human-required steps
6. Cost considerations
7. Implementation difficulty
8. Recommended next step

## AI BUSINESS AUDIT
A deeper analysis of the current process, tool stack, cost/time drivers and implementation path.

Output:
Problem → Current State → Opportunity → Solution → Workflow → Implementation → Measurement → Next Step.

## AI WORKFLOW IMPLEMENTATION
AIMPACT builds the selected workflow using evidence-backed tools and documents the operating procedure.

## AI AUTOMATION RETAINER
Potential recurring service after implementation:
- Workflow monitoring
- Tool changes
- Automation maintenance
- New workflow design
- Optimization
- Team training
- AI intelligence updates

## Measurement
Where data exists, compare:
Before time / cost / manual steps
vs.
After time / cost / manual steps / output.

Never claim savings or ROI that has not been measured.

## Sales funnel
TARGET COMPANY → PROBLEM → OUTREACH → AUDIT → MEETING → PROPOSAL → PAID PILOT → DELIVERY → CASE STUDY → REPEAT → REFERRAL

## Pricing rule
No fixed market price is assumed before customer discovery and paid-pilot feedback. Investment is proposed after scope is understood and approved as a business decision.
