# AIMPACT DEMO CASE — ATELIER DE LUMEN
## DEMO / SIMULATED CASE — NOT A REAL CUSTOMER CASE

Purpose: demonstrate how AIMPACT moves from public business context to a measurable AI workflow. No customer relationship, implementation or result is claimed.

### COMPANY CONTEXT — PUBLIC FACTS
Atelier de LUMEN operates a Korea storefront and an international storefront. Public information shows a Hannam flagship, Shinsegae Centum City, domestic online channels including 29CM and W Concept, W Concept Global and LUXEHOUZE, plus overseas stockists. Its international site publishes product, campaign, shipping and duties/taxes information.

### BUSINESS PROBLEM — SIMULATED HYPOTHESIS
Potential repeated workload: maintaining consistent product and campaign information across domestic/global channels.

This is a hypothesis derived from public operating structure, not a confirmed customer problem.

### CURRENT PROCESS — SIMULATED
Product information
→ merchandising/editorial input
→ channel-specific formatting
→ localization
→ review
→ publishing
→ updates

No claim is made about LUMEN's actual internal process.

### BOTTLENECK — SIMULATED
Potential duplication of product-description, campaign and operational-information formatting across channels.

### AI RESEARCH
Potential capabilities:
- structured product-data extraction
- copy transformation
- translation/localization draft
- channel-format adaptation
- consistency checks
- human approval

### DECISION
Test a human-in-the-loop workflow rather than fully autonomous publishing.

### WORKFLOW
MASTER PRODUCT DATA
→ AI STRUCTURE
→ CHANNEL-SPECIFIC DRAFTS
→ LOCALIZATION DRAFT
→ HUMAN REVIEW
→ PUBLISH
→ CHANGE LOG

### IMPLEMENTATION
1. Define one product-data schema.
2. Define channel-specific output templates.
3. Build AI transformation step.
4. Add human review gate.
5. Log source data and generated versions.
6. Measure actual time and rework.

### MEASUREMENT
Before:
- actual minutes per product/channel
- actual number of manual steps
- actual rework count

After:
- actual minutes per product/channel
- actual manual steps
- actual rework count
- quality exceptions

No numerical improvement is invented.

### EXPECTED OUTCOME
If the hypothesis is correct, the workflow should reduce repetitive formatting/localization work while preserving human control over brand language.

### DATA CAPTURE
Problem → Process → Workflow → Intervention → Before → After → Feedback.
