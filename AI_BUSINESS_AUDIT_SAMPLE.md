# AIMPACT AI BUSINESS AUDIT — SAMPLE

## Objective
Identify one repeatable business process where AI can reduce manual work, improve consistency, or increase throughput.

## 1. INPUT
- Business problem
- Current process
- Current tools
- People / roles involved
- Volume / frequency
- Constraints
- Desired outcome

## 2. PROCESS MAP
PROBLEM → INPUT → MANUAL STEPS → DECISION POINTS → OUTPUT → REVIEW

## 3. AI OPPORTUNITY
For each step:
- AI capability required
- Candidate model/tool
- Human-in-the-loop requirement
- Automation potential
- Data/security considerations

## 4. RECOMMENDED WORKFLOW
INPUT
→ AI ANALYSIS
→ TOOL ACTION
→ HUMAN REVIEW
→ OUTPUT
→ LOG
→ MEASUREMENT

## 5. MEASUREMENT
Before:
- time per task
- manual steps
- cost where measurable
- error/rework where measurable

After:
- time per task
- manual steps
- cost where measurable
- quality/rework
- throughput

No ROI is claimed until before/after evidence exists.

## 6. DELIVERY
AIMPACT provides:
1. Problem diagnosis
2. Workflow design
3. Tool/model selection
4. Implementation plan
5. Measurement plan
6. Review and optimization

## 7. DECISION
Proceed only when the workflow has:
- a real business problem
- measurable value
- acceptable risk
- an implementable path
- a defined owner
